Cada preceptor tiene su vista con sus cursos. Escribí los cursos separados por coma (por ejemplo 3A, 3B, 3C; años 1 a 4, letras A a E). Esta configuración es propia de cada ciclo: podés tener 3C este año y no el próximo. Un curso con alumnos no se puede quitar.

Link para preceptores

Pasales este link a los preceptores (por mail o WhatsApp). Entran directo, sin cuenta ni contraseña, ven y cargan alumnos, y todo se actualiza solo en todas las PC.

Cualquier persona que tenga este link puede ver y modificar los alumnos: compartilo solo con los preceptores. Si se filtra o cambia un preceptor, tocá Generar link nuevo: el anterior deja de funcionar y se vuelve a compartir el nuevo.
